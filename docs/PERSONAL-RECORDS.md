# このブラウザの自己ベスト

- ランキング対象の通常プレイのうち、機能追加後に記録対象の成績で終了した回を、このサイト・このブラウザの IndexedDB にだけ保存する。Easy〜Hardcore は点、Endless は既存ランキングと同じ丸め方の秒数。練習・VS・途中離脱は含まない。
- 旧来の自己ベスト、公開ランキング、会員の同期、バックアップ、移行には接触しない。結果・ランキング表示は従来どおり。別端末・別ブラウザ・別サイトとは共有しない。同じブラウザ環境を使えば、ログインの有無や会員の切替にかかわらず同じ記録になる。ブラウザのサイトデータを消すと復元できない。
- 設定とアカウント画面の「自己ベストの管理」から記録を開ける。難易度ごとに直近24時間の対象を選び、修正後の自己ベストを見て確定する。一度外した記録は同じ時間内に集計へ戻せる。
- 同じ IndexedDB トランザクション内で読込・期限整理・確認時の版照合・まとめて変更を行う。古いタブでの確定は全件止める。期限を過ぎた詳細は次の読込または書込で除き、集計に含まれた点だけを難易度ごとに一つ残す。変更がない古い履歴は表示しない。初期化前のプレイを推定しない。
- 読み書きが失敗しても通常のプレイや従来の保存は止めない。同期やネットワーク送信は追加していない。別タブへの空の更新通知は同一サイト内だけ。
